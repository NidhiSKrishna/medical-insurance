# Medical Insurance Charges Prediction

This project focuses on predicting medical insurance charges using Machine Learning techniques based on individual health and demographic attributes such as age, BMI, smoking status, region, and number of dependents.

The objective of the project is to analyze the relationship between these factors and insurance costs, and to build predictive models capable of estimating medical expenses with improved accuracy.

---

## Project Overview

The workflow of the project includes:

* Data preprocessing and cleaning
* Duplicate value handling
* Feature encoding and scaling
* Exploratory Data Analysis (EDA)
* Correlation analysis
* Regression line visualization
* Model training and evaluation
* Error analysis and prediction visualization
* Web application deployment using Streamlit

---

## Machine Learning Models Used

* Linear Regression
* Ridge Regression
* Random Forest Regressor

The performance of each model is evaluated using regression metrics such as:

* Mean Absolute Error (MAE)
* Mean Squared Error (MSE)
* Root Mean Squared Error (RMSE)
* R² Score
